---
title: クイックスタート
description: インストールから最初のタイムライン取得、agent 連携まで。所要 5 分。
---

**macOS** が必要です（Apple Silicon / Intel）。現在対応しているのは macOS のみです。

<Steps>
<Step title="インストール">

```bash
brew install kentoshimizu/tap/zanei
```

formula は署名・notarize 済みの `Zanei.app` をインストールし、`zanei` コマンドを `PATH` に配置します。

:::note[ソースからビルドする場合]
[packaging の手順](https://github.com/KentoShimizu/zanei/blob/main/packaging/README.md)を参照してください。
素の `cargo install` バイナリは配布物の app bundle ではありません。「+」で追加した権限の行が定着しないことがあり、`dev.zanei.recorder` 宛の reset も効きません。
:::

</Step>
<Step title="記録を開始する">

```bash
zanei start
```

macOS はまず**アクセシビリティ**を確認します。続けて**入力監視**のダイアログが出ることもありますが、出ない機体も少なくありません。その場合は `zanei doctor --fix` — ペインを開き、インストール済み `Zanei.app` の path をコピーし、Finder に表示するので「+」から追加できます。権限が不足している間、`start` は終了コード 3 を返しますが recorder は動いたままなので、そのまま付与できます。オートメーションは Zanei が初めて Chrome に問い合わせるときに別途確認されます。

</Step>
<Step title="再起動して内容記録を選ぶ">

付与できたら、判断を反映するため再起動します。

```bash
zanei stop && zanei start
```

権限がすべて揃った最初の対話式 `start` が、入力テキストとクリップボードの内容を記録するか一度だけ確認します。オフのままなら Enter（既定）、有効にするなら `y`。回答は `config.toml` に保存され、後から `zanei config set capture.text_content <true|false>` で変更できます。最後に recorder 自身の報告を確認します — System Settings に行が見えなくてもこちらが正です（詳細は[権限ガイド](/ja/guides/permissions)）。

```bash
zanei doctor
```

前面ウィンドウに表示された Accessibility text の記録には専用の opt-in があり、既定はオフです。先に `[filter.content_snapshot]` の `include_only_apps` / `include_only_websites` で scope を絞り（アプリ選択には `zanei apps`）、それから `zanei config set capture.content_snapshot true` を実行すると、現在の scope が表示され確認を求められます（詳細は[設定](/ja/reference/config)と[フィルタ](/ja/guides/filters)）。

</Step>
<Step title="タイムラインを取得する">

しばらく普通に作業してから、直近の履歴を取り出してみます。

```bash
zanei timeline --since 15m
```

セッション分割・重複除去済みの Markdown タイムラインが出力されます。これが agent に渡る基本形です。生イベントが見たい場合は `zanei query --since 15m` を使います（[データの取り出し](/ja/guides/timeline)）。

</Step>
<Step title="agent と接続する（任意）">

使っている agent に skill を配置し、MCP の登録コマンドを表示します。

```bash
zanei setup --agent claude
```

以後、agent に「さっきまでの作業を見て続きをやって」と言えば、agent がタイムラインを読んで文脈を復元します。対応 agent 一覧と各種セットアップは [Agent 連携](/ja/agents)を参照してください。

</Step>
</Steps>

## 記録の既定値

- データはローカルの SQLite（`~/.local/state/zanei/store.sqlite`）に保存され、外部には送信されません。
- キー入力の内容は、初回 `start` で選んだ場合にのみ記録されます（既定はオフ。
  `zanei config set capture.text_content <true|false>` で変更可能）。
- 前面ウィンドウに表示されたテキスト（content snapshot）には専用の opt-in があり、既定では記録されません。`zanei config set capture.content_snapshot true` で有効化できます。
- 記録は既定 48 時間で自動削除されます（[設定](/ja/reference/config)で変更可能）。
- 記録したくないアプリやサイトは、[フィルタ](/ja/guides/filters)で書き込まれる前に除外できます。入力テキストの記録と content snapshot には、それぞれ専用のアプリ・サイト単位の scope もあります。

:::note[止めたくなったら]
`zanei pause --for 1h` で一時停止、`zanei stop` で完全停止（データは保持）、`zanei purge --all` で全データ削除です。
:::
